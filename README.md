# 바다몬스터고 (Bada Monster GO)

부산 시민과 관광객이 사진 촬영, 몬스터 포획, 지역 협동 레이드, 위험 생물 공유를 통해 해변 환경과 안전 문제에 참여하는 모바일 우선 환경보호 게임 MVP입니다. 고등학생 팀의 발표와 현장 시연을 위해 외부 API 없이 브라우저에서 바로 실행되도록 제작했습니다.

## 주요 기능

- 시작 화면과 모바일 게임형 홈 대시보드
- 스마트폰 후면 카메라 연결 및 갤러리 이미지 업로드
- 7가지 결과 중 하나를 반환하는 데모 AI 분석
- 쓰레기 종류별 몬스터 출현, 포획 애니메이션과 보상 지급
- 해파리 감지 시 안전 수칙 및 위험 위치 공유
- 부산 4개 해변의 오염도, 쓰레기, 참여자, 미션, 지역 보스 현황
- 오염도를 30% 이하로 낮추면 시작되는 협동 보스 레이드
- 포획 몬스터/미발견 몬스터 도감
- 진행도와 보상이 실제 게임 상태에 연결된 미션
- 실시간 공유를 모사한 바다 안전 지도와 위험 생물 대처 가이드
- 환경 포인트 교환 상점, 포인트 차감 및 교환 내역
- 레벨, 경험치, 배지, 활동 기록이 있는 마이페이지
- `localStorage` 자동 저장과 데이터 초기화

## 기술 구성

- React 19
- TypeScript 5
- Vite 기반 vinext 개발 서버
- Tailwind CSS 4 및 커스텀 모바일 게임 UI
- 브라우저 `localStorage`

## 설치 및 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

터미널에 표시되는 로컬 주소(보통 `http://localhost:3000`)를 브라우저에서 엽니다.

프로덕션 빌드는 다음과 같이 확인할 수 있습니다.

```bash
npm run build
npm run start
```

## 발표/시연 권장 순서

1. 시작 화면에서 **게임 시작**을 누릅니다.
2. 홈에서 **카메라 탐험 시작**을 누릅니다.
3. 스마트폰에서는 사진을 촬영하고, PC에서는 갤러리 이미지를 선택합니다.
4. **AI 분석하기**를 누릅니다. 결과는 무작위이므로 쓰레기, 해파리, 일반 물체 중 하나가 나옵니다.
5. 쓰레기 결과라면 몬스터를 포획해 경험치, 포인트, 도감, 미션 변화를 확인합니다.
6. 해파리 결과라면 **위험 위치 공유하기**를 누른 뒤 안전 지도에서 신고를 확인합니다.
7. 지도에서 오염도 30% 이하인 송정을 선택하면 즉시 보스 레이드를 시연할 수 있습니다.
8. 마이페이지의 환경 포인트 카드에서 상점으로 이동해 상품을 교환합니다.
9. 새로고침 후 포인트, 포획 수, 신고, 교환 내역이 유지되는지 확인합니다.

## 게임 규칙

- 몬스터 포획: 몬스터별 경험치와 게임/환경 포인트 지급, 해당 지역 오염도 6% 감소
- 일반 정화 활동: 공동 정화량 50 POINT 증가, 지역 오염도 5% 감소
- 보스 출현: 지역 오염도 30% 이하
- 보스 공격: HP 20 감소
- 보스 클리어: 150 EXP, 희귀 보스 도감 등록, 환경 포인트 500 지급
- 상품 교환: 환경 포인트 차감 후 교환 내역 저장

## 데이터 저장

모든 데모 데이터는 브라우저의 `badamonstergo-state-v2` 키에 JSON으로 저장됩니다. 따라서 같은 브라우저와 기기에서는 새로고침 후에도 유지됩니다. 마이페이지 하단의 **게임 데이터 초기화** 버튼으로 최초 상태로 되돌릴 수 있습니다.

## 프로젝트 구조

```text
app/
├─ data.ts          # 몬스터, 해변, 미션, 상품 초기 데이터
├─ game-app.tsx     # 전체 화면, 게임 로직, localStorage 상태 관리
├─ globals.css      # 모바일 게임 UI, 애니메이션, 반응형 스타일
├─ layout.tsx       # HTML 레이아웃과 메타데이터

└─ types.ts         # 게임 데이터 TypeScript 타입
public/             # 정적 파일
.openai/            # 호스팅 설정
package.json        # 실행 및 빌드 스크립트
vite.config.ts      # Vite 설정
```

## 실제 서비스로 확장할 때

### 실제 AI API

`app/game-app.tsx`의 `analyze()`에서 현재 무작위 결과를 생성하는 부분을 이미지 분류 API 호출로 교체합니다. 이미지 원본은 서버/R2 같은 객체 저장소에 업로드하고, API 키는 브라우저 코드가 아닌 서버 환경 변수에 보관해야 합니다.

### 실제 지도 API

`BeachMap`과 `SafetyMap`의 데모 카드/도식 영역을 Kakao Maps, Naver Maps 또는 공공데이터 기반 지도 컴포넌트로 교체합니다. 신고 데이터에 위도와 경도를 추가하고 개인정보 보호를 위해 위치를 적절히 흐리게 표시해야 합니다.

### 데이터베이스와 다중 사용자 레이드

현재 `localStorage` 상태를 사용자, 해변, 포획, 미션, 신고, 레이드 기여, 교환 내역 테이블로 분리해 서버 데이터베이스에 저장합니다. 다중 사용자의 실시간 오염도와 보스 HP 동기화에는 WebSocket/SSE 또는 짧은 주기의 조회가 필요합니다. 로그인, 중복 보상 방지, 신고 검증, 관리자 기능도 함께 추가해야 합니다.

### 포인트/동백전 연계

현재 포인트와 상품은 시연용이며 실제 가치나 지급 기능이 없습니다. **향후 부산시 및 동백전과 협의 후 연계 가능한 기능**이며, 실제 구현 시 제휴 승인, 정산, 본인 인증, 부정 사용 방지, 이용약관 검토가 선행되어야 합니다.

## 현재 제한 사항

- AI 판별은 실제 모델이 아닌 무작위 데모입니다.
- 지도는 실제 GPS/지도 API가 아닌 부산 해변 목록 기반 데모입니다.
- 레이드 참여자 수와 공동 진행도는 한 기기의 로컬 데이터이며 실제 다중 사용자 동기화가 아닙니다.
- 위험 신고는 기관에 전달되지 않으며 시연 브라우저에만 저장됩니다.
- 쿠폰과 동백전 포인트는 실제 발급되지 않습니다.
- 이미지 파일은 미리보기만 하며 새로고침 이후 보관하지 않습니다.
